# NAND2Tetris
# 💻 NAND2Tetris — Building a Computer from Scratch

A hands-on implementation of the **NAND2Tetris course**, exploring how a complete computer system is constructed from fundamental logic gates to computer architecture.

This repository documents my learning journey through digital logic, Boolean arithmetic, sequential circuits, memory systems, and computer architecture.

---

## 📌 About the Project

NAND2Tetris is an educational project based on the book *The Elements of Computing Systems* by Noam Nisan and Shimon Schocken.

The main objective is to understand how computers work internally by building their components from the ground up, starting with a simple NAND gate.

Instead of treating a computer as a black box, this project explores the fundamental concepts behind its hardware and architecture.

## 🎯 Objectives

- Understand the fundamentals of digital logic and Boolean algebra.
- Design logic gates using Hardware Description Language (HDL).
- Implement arithmetic circuits such as adders and ALUs.
- Understand sequential circuits and memory organization.
- Explore registers, RAM, and data storage.
- Learn the internal architecture of a computer system.
- Apply theoretical concepts through practical implementation.

## 🛠️ Technologies & Tools

- **Hardware Description Language (HDL):** Designing and implementing digital circuits.
- **NAND2Tetris Hardware Simulator:** Testing and simulating hardware components.
- **Digital Logic Design:** Understanding gates, circuits, and Boolean expressions.
- **Computer Architecture:** Studying the internal organization of a computer.

## ⚙️ How to Explore the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/yokshitrajora/NAND2Tetris.git
   ```

2. Navigate into the repository:

   ```bash
   cd NAND2Tetris
   ```

3. Open the required project folder.

4. Open the HDL files using the official NAND2Tetris Hardware Simulator.

5. Run the corresponding test scripts to verify the hardware implementations.
